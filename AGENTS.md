# jstack

Public repo of agent skills, installed with `npx skills add digitalknk/jstack -g` and updated with `npx skills update -g <skill> -y`.

- Edit skills here, never the installed copies.
- Every PR that changes a skill bumps `metadata.version` in that skill's SKILL.md: minor for new or changed rules, patch for wording fixes. The version is how anyone can tell an installed copy is current.
- The repo is public. Paraphrase the user instead of quoting them, and leave out names of their products, clients, people, and personal details.
- Describe a pattern on its own terms. Don't name a website as the source of a rule, since the site may disappear. Linking a tool the skill tells agents to use is fine.
