# jstack

My agent skills.

| Skill | What it does |
| --- | --- |
| [ouroboros-design](skills/ouroboros-design/SKILL.md) | Designs, redesigns, critiques, and builds user-facing interfaces |
| [ouroboros-copy](skills/ouroboros-copy/SKILL.md) | Writes and edits the words in a product or site |
| [the-algorithm](skills/the-algorithm/SKILL.md) | Simplifies a process before building or automating it: question, delete, simplify, speed up, automate last |

## Install

```sh
npx skills add digitalknk/jstack -g
```

Add `-s ouroboros-design` to install one skill.

## Update

```sh
npx skills update -g
```
